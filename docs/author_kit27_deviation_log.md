## D1 — §4.3.2 式(16)：补录 β 的箱约束 $\beta \in [-3,3]$

**裁定**：2026-09-22，西瓜先生裁定「修改箱约束 β∈[−3,3]，但是要在一个文档中汇总说明对原件的
修改具体内容」—— 本文件的由来即此。

**位置**：`paper/main.tex` 第 336–341 行（`\label{eq:beta-fit}`）。
对应原件 §4.3.2「注意力质量偏置拟合」（原件抽取文本第 268–312 行）。

### 原件原文（逐字，公式按抽取碎片还原）

> 仅保留 Key 子集会减小远程块对全局 Softmax 分母的贡献。对代表 Query $\widehat{q}_{r,a}$，定义完整块的
> Logit 与非归一化质量，以及紧凑 Key 的响应矩阵：……（式 15）
>
> 其中 $m^{s\to r} \in \mathbb{R}^M$，$G^{s\to r} \in \mathbb{R}^{M \times B_{s,r}}$。令
> $w_j = \exp(\beta_j) \ge 0$，则带偏置紧凑块的质量为 $\widehat{m} = Gw$。我们通过**非负岭回归**拟合
>
> $$w^* = \arg\min_{w \ge 0} \left\|G^{s \to r} w - m^{s \to r}\right\|_2^2 + \lambda_\beta \left\|w - \mathbf{1}\right\|_2^2,
> \qquad \beta_j^{s \to r} = \log\left(\max\{w_j^*, \varepsilon\}\right). \tag{16}$$
>
> $w_j$ 表示紧凑 Key 所承载的等效注意力质量，可聚合若干被删除 Key 的指数响应；正则项在拟合信息不足时
> 将其收缩至无偏置状态 $w = \mathbf{1}$。**非负约束保证 $w$ 可映射为 Logit 偏置。** 实现中应以逐行
> 最大值平移计算指数项，并在拟合目标中保留相应的行缩放，以避免数值溢出。

⇒ 原件式(16) 的可行域**只有下界 $w \ge 0$**（等价于 $\beta$ 只有下界、无上界），**没有箱约束**。

### 重建稿改后

```latex
\begin{equation}
w^* = \arg\min_{e^{-3} \le w \le e^{3}} \left\|G^{s \to r} w - m^{s \to r}\right\|_2^2
      + \lambda_\beta \left\|w - \mathbf{1}\right\|_2^2,
\label{eq:beta-fit}
\end{equation}
其中 $\beta_j^{s \to r} = \log(\max\{w_j^*, \eps\})$。
```

> **为什么 β 的定义在式外**：它原本与目标函数同处一个 `equation`。但 `acmart` 下在 `equation` 内嵌 `split`/`gathered`、且下标含 `\le`（这里是 `e^{-3} \le w \le e^{3}`）时，xelatex 会报 `! Argument of \split has an extra }.`（实测 split 形态 22 个错误、gathered 形态 1 个错误，单行形态 0 个错误；最小 article 文档复现不出）。**这是排版约束，不是内容偏离。**

并在式后补一句说明：箱约束等价于 $\beta_j^{s \to r} \in [-3,3]$，取自源论文附录 C.2 对 RMS 选键
分支的配置。

**改的是可行域的“上界”，不是下界。** $e^{-3} > 0$ 已经蕴含 $w \ge 0$，故原件「非负约束」的表述被
**包含**而非被替换 —— 这一点是刻意保持的，避免削弱原件论点的连续性。

### 为什么改

1. **实现本来就是这样跑的，属于「实现先于纸面」。**
   `src/dcc_kv_ref/calibration.py:215-216` 把求解投影到 $[\exp(-\beta_{\text{bound}}), \exp(\beta_{\text{bound}})]$
   的 $w$ 箱内（第 138 行做双侧 clamp）；`calibration.py:231` 再把 $\beta$ 二次 clamp 到 $[-3,3]$。
   默认 `DEFAULT_BETA_BOUND = 3.0`（`calibration.py:60`）。即**箱约束自始存在，只是式(16) 没写**。
2. **§6 早已披露它，§4 却未定义 ⇒ 存在正文内部缺口。**
   `paper/sections/06-experiment.tex:54-55` 写明「β 的校准参数在当前实现中取固定默认值：箱约束
   $[-3,3]$ 与 $\lambda_\beta = 3\times10^{-2}$」，表 `tab:knob` 的 caption（同文件 :631）也标了
   「箱约束 $[-3,3]$」。补录式(16) 是**让 §4 的定义与 §6 的实现声明一致**，消除「正文不写、实验却用」。
3. **依据可追溯，非本文发明。** $[-3,3]$ 取自源论文 Attention Matching 附录 C.2 对 RMS 选键分支的配置；
   `calibration.py:187` 与 `compact_kv.py:80` 的 docstring 均如此注明。
4. **实测无副作用，且它不是惰性项。**
   一次性诊断（`_onetime_scripts/checks/_diag_box_constraint.py`，产物 `_diag_out/box_constraint/`，
   box on/off × {$\lambda_\beta = 3\times10^{-2}$, $0$} 对照）：默认 $\lambda_\beta$ 下箱约束的
   **中位绑定率为 $0$**、单格最大 $|\Delta|$ 约 $0.038\%$；而 $\lambda_\beta = 0$ 时中位绑定率升到
   $6.25\%$ ⇒ **它在正则项缺席时确实承压**，属于第二道防线而非摆设。

### 影响面

- §4.3.2 的公式表述改变 ⇒ 本文 §1–4 出现**第一处内容级偏离**（即 D1）。
- **§6 无需改动**（本来就写了箱约束）。
- **数值结论不受影响**：实测影响量级 $0.038\%$，远小于 E9/E11 的格间散布。
- **算法伪代码无需改**：原件 §4.4 步骤 7「用 eq. (16) 拟合 $\beta^{s\to r}$」引用的是式(16) 本身，
  式(16) 内容变了它自动跟随。
- **式编号不变**：`\label{eq:beta-fit}` 未动，全文 `\eqref{eq:beta-fit}` 引用不受影响。
