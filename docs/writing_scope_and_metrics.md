## 2. 误差度量：论文术语 ↔ 代码函数 ↔ §5 定义

**这是当前最实质的文字缺口。** 论文中出现了六个误差术语，没有任何一处声明它们与 §5
的 $\epsilon_{\text{mass}}$、$\epsilon_{\text{out}}$ 的对应关系；代码中相应存在**四套并存**的
度量实现。下表是本文件的核心。

| 论文术语 | 代码函数（`experiments/common/synthetic.py`） | 口径 | 与 §5 理论量的关系 |
|---|---|---|---|
| $\epsilon_{\text{mass}}$（式 35） | — | 跨源块 $\sum_{s\in\mathcal{E}_r}$、绝对 | **理论量** |
| 「绝对质量误差」 | `absolute_mass_error` | 公共偏移 $c=\max(\ell_{\text{full}})$，单块 | 理论量的**单块版**（未跨块求和、未加权） |
| 「单块误差」 | `mass_error`（**旧口径，已废弃**） | 两侧各减自身最大值 ⇒ 对 $\beta$ 的**常数分量免疫** | **不得再用于 $\beta$ 相关结论** |
| $\epsilon_{\text{out}}$（式 36） | — | 跨源块 $\sum_s M_s(q)\|\cdot\|_2$、绝对 | **理论量** |
| 「留出输出」/「相对输出误差」 | `relative_output_error` | 单块，除以 $\|y_{\text{dense}}\|_2$ | 理论量的**单块归一化版** |
| 「留出归并」/「归并误差」 | `mixture_relative_error` | 源块 + 固定上下文块拼接后再与 Dense 比 | **最接近式(37) 的界所约束的量** |

### 2.1 由此得到的三条硬结论

1. **论文中所有实验数字都是「理论量的单块版」。** 而 §5 的界是跨块版。
   二者之间没有已测量的桥 ⇒ **式(37) 的界从未被数值检验过紧致程度**（缺口 M3）。
   正文现在把「误差不随块数发散」当作已论证的性质，但它依赖的是**未经检验**的界。
2. **报任何误差数字时必须同时声明三件事**：是单块还是归并侧、是否归一化、用哪套偏移。
   仅写「误差 0.42」在信息上是不完整的 —— 换一套度量可以得到完全不同的数。
3. **`mass_error`（旧口径）与 `absolute_mass_error`（新口径）的结果不可互比**；
   E2 的早期落盘用前者、E2b 用后者，二者在正文中并列出现时须知会读者。

## 5. 口径硬约束（不得违反）

1. **评估 Query 不得参与选键、$\beta$ 拟合或 $V$ 回归。** 否则「增大 $M$」自动获胜，
   结论退化为同义反复。E9 的 oracle 是**作弊上界**，只用于界定 $B$ 的表示能力，
   绝不可作为可实现精度报告。
2. **报「预算–精度」曲线时必须同报 $M$。** 否则读者无法区分「预算不够」与「估计不足」。
   A2 只能称**参考曲线**，不得称帕累托前沿（两轴当前不同源）。
3. **四项计时不可合并。** $T_{\text{build}}$ / $T_{\text{comm}}$ / $T_{\text{comp}}$ / $T_{\text{total}}$
   分开报；窗口内只做 `cuda.synchronize`，不得含 `dist.barrier`。
4. **阈值一律走单一事实源**（`experiments/common/hypotheses.py`），不得在脚本里写魔法数字。
5. **压缩机制（Key 选择 / $\beta$ / $V$ 回归）源自 Attention Matching，不得主张为原创。**
6. **不得主张**任务质量、通信性能、多卡可扩展性、与基线的对比优势 —— 这四项均无证据。
7. **拿不准的前提不得作为结论写入**（§6 小结末句）。
